## What is LLTHW?

**Learn Languages the Hard Way** is a public experiment in self-directed language acquisition.

The core idea is simple:

> Treat language learning like building software.

That means:

- Work in public
- Make regular pushes
- Track what changes
- Build reusable tools
- Document the process
- Improve the system over time

This is not about pretending there is a secret shortcut to fluency.

It is about building a durable system and executing it consistently.

---

## Core Principles

LLTHW is built around:

- **Daily practice** — small, consistent effort beats occasional heroic effort.
- **Structural understanding** — grammar, syntax, and pronunciation matter.
- **Utility-first vocabulary** — learn the words that unlock the most language first.
- **Active recall** — if you cannot produce it, you do not really know it.
- **Public accountability** — document the work, the mistakes, and the progress.

## Active Project

### Learn Italian the Hard Way

Italian is the first active LLTHW project.

The early system uses Spanish as the primary anchor language because Spanish and Italian are closely related, and because learning from a nearby language may be more efficient than routing everything through English.

Current priorities:

- Personal pronouns
- Articles
- Core conjunctions
- High-utility verbs
- Pronunciation
- Anki card architecture

## Philosophy

You do not learn a language by downloading an app and cosplaying productivity.

You learn a language by showing up, wrestling with structure, forgetting things, remembering them again, and slowly becoming the kind of person who can think in another language.

LLTHW exists to document that process.
